# notype 本機試用

本輪提供這台 Windows 11 x64 的私有本機試用包：錄音 → 繁體中文＋英文／簡體中文＋英文本機辨識 → 文字歷史 → 複製。現在不需要 API key。公司文字整理、翻譯與隨便問的實際生成品質，以及其他 App 自動輸入，留待後續。

## 啟動與第一次使用

1. 在檔案總管雙擊 `D:\git\notype-local-artifacts\Start-notype.cmd`；也可按 Win＋R 貼上此路徑。使用一般使用者開啟。啟動時會驗證完整套件，首次模型啟用可能需要數十秒，請等 notype 視窗出現。
2. 第一次若出現模型選擇，選擇**已安裝的 Qwen3-ASR 0.6B Q6_K**。模型已隨包提供，可直接選用。
3. 在一般設定選擇「繁體中文＋英文」或「簡體中文＋英文」辨識模式；預設繁體。介面語言另行設定，切換介面不會改寫歷史。
4. 按一下 **Right Alt** 並放開，等收音提示出現再說話；再按一下 **Right Alt** 停止。Esc 可取消錄音或處理。
5. 等辨識完成，開啟「文字歷史」，找到當次「原稿」，按「複製原稿」，再到需要的 App 手動貼上。

文字服務尚未設定時，歷史會顯示「整理失敗，原稿已保存」及設定提示；本機辨識原稿仍可檢視、搜尋及複製。之後有公司 API 時可從原稿重試文字處理，不需要長期保存錄音。

## 三場景與提示詞

| 操作 | 預設快速鍵 |
| --- | --- |
| 開始口述 | Right Alt |
| 開始翻譯 | Right Alt＋Right Shift |
| 開始隨便問 | Right Alt＋Space |
| 停止目前錄音 | Right Alt |
| 取消 | Esc |

開始鍵與共用停止鍵可在設定修改。三份提示詞可於「文字整理」中的「場景提示詞」獨立編輯、保存；「還原此預設提示詞」只還原所選場景。翻譯與隨便問要產生譯文或回答，仍需後續設定公司文字 API。回譯預設關閉。

## 資料與結束

| 用途 | 此試用入口的位置 |
| --- | --- |
| 程式套件 | `%LOCALAPPDATA%\notype\local-app` |
| 試用資料、模型與設定 | `%LOCALAPPDATA%\notype\local-trial` |
| 文字歷史資料庫 | 試用資料目錄內的 `sessions.db` |

試用資料位於 npm 程式與建置快取之外。請保留整個 `local-trial` 目錄；文字歷史會保留到手動刪除。此入口使用獨立試用目錄，既有預設 App 資料仍在原處。

按主視窗的 X 會收至 Windows 通知區；可從 notype 托盤重新開啟視窗，或從托盤選單結束程式。

實際麥克風、人聲品質及實體快捷鍵仍需在你的使用環境試用。[完整套件驗證](verification/portable-local-assembly.md) 記錄實際離線安裝、CPU 辨識、GUI 與限定更新結果；合成語音、程式審查與效能數據另見 [Qwen 驗證](verification/qwen3-quality.md) 及 [審查紀錄](verification/local-code-review.md)。這些結果不代表完整 session p95、公司環境或五個 App 驗收通過。
