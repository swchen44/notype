# Speech-model package role

Unassembled private role, not a shipping model selection or quality claim. The final package must pin a quality-accepted model, its tokenizer/config/support files, source revision, hashes and actual redistribution notices. It is a functional dependency of notype, independently versioned to avoid re-fetching unchanged weights on app updates. No runtime download or install scripts are permitted.

Local verified copy/atomic activation into the existing persistent models directory and native catalog selection remain final #14 integration work. Do not delete existing user models or recordings as package maintenance.
