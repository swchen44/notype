# notype 離線包

將 ZIP 全部解壓到一般使用者可讀取的本機資料夾，再雙擊
`Start-notype.cmd`。程式、完整執行環境與隨附語音模型均在離線包內，
首次啟動不需另裝 Node、開發工具或下載模型。

保留 `runtime`、`app` 與啟動檔的完整內容。程式缺檔或驗證失敗時，
請重新取得完整且可信任的離線包；程式不會自動修復或下載。

首次使用請依畫面完成設定。隨附模型可用於本機語音辨識，不需要 API key。
如果管理者附上預設文字連線，連線中的 key 仍是空白；請在 App 的連線設定
輸入自己的 key 並儲存。未附預設連線時，可自行新增。程式不會因匯入預設而
自動列出遠端模型、測試連線或送出文字，請在需要時自行操作。

已有的模型資料夾、選用模型、連線、key、提示詞與偏好設定優先於離線包預設。
「設定尚未完成」時，可進入設定或模型資料夾畫面修正並重試；原有文字歷史
仍可查閱。缺少語音模型時，請選取已有模型的資料夾，再重新掃描。

模型資料夾可獨立保留，並可在程式結束後自行搬移整個 `models` 資料夾。
重新安裝或搬移後，在 App 選取新位置並重新掃描。App 不會替您搬移、複製、
刪除或重新下載已有權重，也不會因原位置遺失而自行改選其他資料夾。
請保留模型資料夾中的模型資訊與授權說明；唯讀模型資料夾也可使用。

關閉視窗的 X 會將程式保留在系統匣。要結束程式，請從系統匣選擇「結束」。
個人設定與文字歷史存放在程式及模型資料夾之外；更新或移除離線包不會刪除它們。
請勿把個人設定、key、錄音或歷史資料放進離線包再轉送他人。
