# Unit tests

放置單一模組透過公開介面可驗證的行為測試。測試需可重現，日常執行不依賴公司 API、真實麥克風、GUI 或完整語音模型。

首批實作應涵蓋：

- 語音 session 的成功、取消與錯誤狀態；取消後結果不會交給輸入流程。
- LLM 錯誤／timeout 後保留逐字稿，等待重試或貼原稿的選擇。
- API adapter 對約定 response、錯誤及不合法輸入的可觀察處理；使用者內容與程式設定的邊界。
- 輸入交付的去重與復原策略，以及 portable 設定／模型路徑驗證。
- 長期文字歷史的寫入／讀取／刪除、原稿與整理結果關聯；原稿／整理結果／時間／狀態保留到手動刪除，與當次錄音清理分開。

測試行為以 [決策紀錄](../../docs/research/08-decision-log.md) 為準，研究建議不能自行替代已確認需求。

LLM 實際文字品質及 STT 辨識率屬 integration／品質驗收，不能以 mocked 回應證明模型正確。

目前沒有產品測試檔；實作對應模組時，將測試檔加入本目錄並在 `tests/README.md` 補上可執行命令。
